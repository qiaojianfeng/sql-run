# 学习文档维护

每篇教程独立放在 `lessons/*.md`。Vite 自动加载这个目录下的 Markdown 文件；新增教程无需修改 TypeScript 或目录配置，开发服务会自动更新。

文件名建议采用 `01-select.md` 的形式，实际显示顺序由 frontmatter 的 `order` 决定。

## 文件格式

````markdown
---
id: select
order: 1
category: 查询基础
summary: 认识表、行和列，选择字段并为结果命名。
---

正文使用标准 Markdown。用 `SELECT` 标记行内代码，也可以写 **重点**、列表、链接和表格。

| `SELECT` | 指定结果列 |

````

- `id` 使用小写字母开头，可包含数字和连字符；全目录唯一。建议加双引号，尤其是 `"null"` 这类 YAML 保留值。
- `order` 是全目录唯一的正整数。`category` 自动生成目录分组，`summary` 显示在标题下。
- 一级标题是教程名称，二级标题划分章节；至少有一个正文章节。正文中更细的层次从三级标题开始。
- `学习目标`、`SQL 示例`、`结果解读`、`巩固练习`、`学习提醒` 是必填的保留章节名，请勿重复。其他二级标题自动出现在本篇目录中。
- `学习目标` 使用无序列表。`SQL 示例` 中只放一个标注为 `sql` 的围栏代码块，页面将它作为可复制、可载入实验台的示例。正文中也可以放解释用的代码块。
- 正文支持 GFM 表格、列表、强调、链接和代码块，原始 HTML 不作为页面元素执行。表格单元格中的竖线请写成 `\|`。
- 搜索会包含元信息、正文、SQL 示例及全部辅助章节。教程数量和上下篇导航自动更新。

## 验证

```bash
pnpm typecheck
pnpm test
pnpm build
```

格式校验会报告文件路径和具体问题；测试会在独立的默认学习库中运行每篇教程的 SQL 示例。修改示例结果时，请同步修改结果解读及相关测试。
