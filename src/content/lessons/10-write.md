# INSERT、UPDATE、DELETE：修改数据

## 学习目标

- 按字段列表新增记录
- 先检查再修改
- 理解约束失败后的处理

## 新增记录

`INSERT INTO` 后写表名和明确的字段列表，`VALUES` 中的值与字段顺序一致。主键必须唯一，外键引用的目标应存在，数据还需满足 `NOT NULL`、`UNIQUE` 和 `CHECK` 等约束。

## 限制修改范围

`UPDATE` 用 `SET` 指定新值，`DELETE FROM` 删除记录。没有 `WHERE` 时会影响所有行。执行前先用相同 WHERE 写 SELECT 检查目标；执行后再次查询确认。已提交的修改会保存在本地，刷新不能代替撤销；重置前请按需导出备份。

## 写入前后的检查清单

字段和值按位置一一对应。明确字段列表可以避免表增加字段之后，旧 INSERT 因顺序变化而写错内容。省略字段不等于可以省略所有必填信息，数据库还要检查默认值、空值和约束。

- 修改前：使用相同 WHERE 写 SELECT，确认目标行和数量。
- 修改时：只 SET 必要字段；DELETE 删除的是整行，不是某个字段。
- 修改后：查看影响行数，再次查询确认实际结果。
- 提交前：确保操作完整，失败时明确执行 ROLLBACK。

## 约束报错应先理解规则

默认成绩表的分数范围为 0～100，同一学生与课程的组合必须唯一。外键还要求学生、课程真实存在。删除被成绩引用的学生时，也会受到引用约束限制。

不要为了让 SQL 通过而直接关闭约束。先检查是否写错编号、缺失必填字段或违反唯一规则。本工具在出错处停止当前批次，错误之后的回滚语句不会自动运行，应单独执行 `ROLLBACK;` 再继续。

## SQL 示例

```sql
BEGIN;
INSERT INTO students (id, name, gender, age, class_name, city, enrolled_at)
VALUES (100, '测试同学', '女', 20, '计算机一班', '北京', '2025-09-01');
UPDATE students SET age = 21 WHERE id = 100;
SELECT * FROM students WHERE id = 100;
DELETE FROM students WHERE id = 100;
ROLLBACK;
```

## 结果解读

事务内可以看到测试学生的年龄已变为 21。完整执行后测试记录不存在，原有学习数据保持不变。可选中中间的 SELECT 单独运行，观察逐步执行的状态。

## 巩固练习

在事务中把 id 为 1 的学生城市改成另一座城市，查询后回滚，再查询验证已恢复。

## 学习提醒

示例用事务回滚清理修改。若执行中遇错，后面的 ROLLBACK 不会自动运行，请手动回滚或重置实验库。
