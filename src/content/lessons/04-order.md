# ORDER BY 与 LIMIT：排序和分页

## 学习目标

- 用唯一字段稳定并列顺序
- 计算分页偏移量
- 区分前几行与前几个名次

## 显式指定排序

没有 `ORDER BY` 的结果顺序没有保证。`ASC` 为升序，`DESC` 为降序。多个排序字段依次生效；如果分数相同，增加唯一 `id` 作为第二排序字段可以稳定结果。

## 限制返回条数

`LIMIT 5` 返回前五行，`LIMIT 5 OFFSET 5` 跳过前五行再返回五行。分页通常需要配合稳定排序。大偏移量的分页可能较慢，后续可以学习按主键范围分页。

## 同分记录如何决定先后

`ORDER BY score DESC, id ASC` 先按成绩降序，成绩相同再按编号升序。只按非唯一字段排序时，并列记录之间没有确定顺序，分页边界也可能不稳定。

“前五行”和“前五个名次”是两个需求。`LIMIT 5` 固定取五行；若第五名有多位同分者，想全部保留就需要排名函数等写法，不能只增加一个 LIMIT。

## 从偏移分页到游标分页

页码从 1 开始、每页 n 行时，偏移量是 `(页码 - 1) × n`。使用相同排序规则，第一页写 `LIMIT 5 OFFSET 0`，第二页写 `LIMIT 5 OFFSET 5`。

大量数据跳过很大的偏移量可能产生额外开销。按唯一递增编号浏览时，可用 `WHERE id > 上页最后编号 ORDER BY id LIMIT 5`，这是一种游标分页。多字段排序需要同时考虑全部排序键。

- 排序作用于结果，不会改变表中数据。
- 即使排序稳定，两次翻页之间的数据增删仍可能让偏移分页重复或漏行。
- 先排除或明确处理 NULL，再讨论成绩排名的业务含义。

## SQL 示例

```sql
SELECT student_id, course_id, score
FROM scores
WHERE score IS NOT NULL
ORDER BY score DESC, id ASC
LIMIT 5 OFFSET 0;
```

## 结果解读

最高分为 96，其次有两条 95 分成绩。同分行按成绩记录 id 升序展示；把 OFFSET 改为 5，可以查看下一页。

## 巩固练习

查询年龄最大的三名学生，年龄相同按 id 升序，再查询第二页三名学生。

## 学习提醒

需要明确将空值放最后时，可使用 `ORDER BY score IS NULL, score DESC, id ASC`，把展示意图写进排序表达式。
