# SELECT：读取你的第一张表

## 学习目标

- 认识默认学习库
- 明确选择字段与别名
- 区分查询结果和原始数据

## 表、行与列

`students` 表的一行代表一名学生，`name`、`age` 等列描述学生的属性。`SELECT` 指定要返回的列，`FROM` 指定数据来源。SQL 关键字通常大写，便于阅读。

## 选择列与别名

`SELECT *` 返回全部字段，探索数据时很方便；正式查询建议列出字段。`AS` 可以为结果列命名，别名不会修改原始表结构。语句以分号结束，文本值使用单引号。

## 读懂默认学习库的关系

学习 SQL 时，先弄清“每行代表什么”。学生表记录人，课程表记录课程，成绩表记录某人在某门课上的一次成绩。学生可能重名，因此关联时使用唯一编号，而不使用姓名。

三张表中的同名字段也不一定含义相同：`students.name` 是学生姓名，`courses.name` 是课程名称。后面的关联教程会使用表别名区分它们。

| 数据表 | 一行代表什么 | 常用字段 |
| --- | --- | --- |
| `students` | 一名学生，共 12 人 | `id`、`name`、`age`、`class_name` |
| `courses` | 一门课程，共 5 门 | `id`、`name`、`teacher`、`credit` |
| `scores` | 一条成绩，共 26 条 | `student_id`、`course_id`、`score` |

## 建立清晰的查询习惯

阅读查询时，先看 `FROM` 确定来源，再看 `SELECT` 确定输出。字段之间用逗号分隔，主要子句单独换行，能让后续添加筛选和关联更容易。

表达式也可以作为输出列，例如 `age + 1 AS 明年年龄`。它只改变查询结果，不会修改学生年龄；同样，`name AS 姓名` 也不会重命名表中的字段。

- 定位具体记录时保留 `id`，避免姓名相同造成混淆。
- 文本用单引号，如 `'杭州'`；数字可以直接写 `20`。
- 没有 `ORDER BY` 时，不能依赖当前看到的行顺序。

## SQL 示例

```sql
SELECT id, name AS 姓名, age AS 年龄, class_name AS 班级
FROM students;
```

## 结果解读

默认数据返回 12 行，每行是一名学生，结果列标题使用中文别名。切回表结构会发现字段仍叫 `name` 和 `age`，说明别名只影响本次输出。
